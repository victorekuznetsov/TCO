# Модель TCO буровых станков по методике аннуитета (руб/пог.м и руб/м³)

`Модель_TCO_буровых_станков_аннуитет.xlsx` — расчётный файл для экономического
сравнения буровых станков **одного класса** по совокупной стоимости владения за
полный жизненный цикл. Построен по аналогии с моделью экскаваторов (соседняя ветка),
но с расчётом **производительности по методике из корпоративного файла буровых
станков** (`000_БСЛ-2027`). Генерируется скриптом `build_drill.py` (Python + openpyxl).

```bash
pip install openpyxl formulas
python3 build_drill.py
```

## Метрика

Главный критерий — **удельный аннуитет затрат, руб/пог.м** пробуренной скважины,
и производный **руб/м³** взорванной горной массы (через выход м³ с 1 пог.м).
Аннуитет разложен на **операционный** и **инвестиционный**. Лучший вариант — минимум.

```
Аннуитет (руб/год)      = NPV затрат / Σ(дисконт-факторов)
Удельный (руб/пог.м)    = Аннуитет (руб/год) / годовой объём бурения (пог.м)
Удельный (руб/м³)       = руб/пог.м / выход (м³ с 1 пог.м)
```

Модель **пост-налоговая**: годовой поток = денежные затраты × (1 − налог) − налоговый
щит амортизации. Инвестиционный аннуитет = (цена − дисконт. остаточная) / Σ(диск.факторов).

## Производительность (методика бурения, лист «W час» исходного файла)

Ключевое отличие от модели экскаваторов — часовая производительность считается по
**физике бурения**, а не по геометрии ковша:

```
Теор. скорость бурения (п.м/час) = (0,1 · N_вращ) / (2,73^(0,017·σ) · D_заряда²)
D_заряда = D_долота · k_разбура
Время цикла скважины = бурение + продувка + наращивание + подъём става + разбор + переезд
Скважин/смену        = смена / время цикла
Часовая произв.      = скважин/смену · средняя глубина / смена
КИО                  = КТГ · (1 − простои_смены/(60·смена))
Эффективное время    = КФВ · КИО
Объём бурения (тыс.пог.м) = часовая · эфф.время
Объём взрывания (тыс.м³)  = объём бурения · выход (м³/пог.м)
```

Часовая производительность модели **совпадает с исходным файлом**: DR75 16,31;
SWDRT250SM 17,59; SWDRT270SM 20,04; SWDRT270B 20,04; HIFO 75D 16,31 п.м/час.

## Что учитывает (полный погодовой жизненный цикл, 10 лет)

- **CAPEX**: цена (в валюте контракта по курсу), доставка/монтаж/ПНР, остаточная стоимость.
- **OPEX по годам**: топливо/энергия, ТОиР и сервис (ТО, текущие и капитальные/ППР
  ремонты, трудозатраты — задаются по годам из данных поставщика; «рваный» график
  капремонтов учитывается дисконтированием), буровой инструмент (долота, штанги),
  расходники, персонал, транспортный налог.
- **Финансы**: амортизация (НУ), налог на прибыль (щит), дисконтирование, аннуитет.

## Листы

`Методика` · `Дашборд` (KPI, рейтинг, графики) · `Параметры` · `Ввод данных`
(до 5 станков: цена, физика бурения, персонал) · `Поставщик 1…5` (по машине: КТГ,
простои, ТОиР по годам, расход ДТ, буровой инструмент) · `Данные по годам` (сводка,
тянет из шаблонов) · `Производительность` (физика бурения + погодовая таблица) ·
`Денежный поток` (погодовой пост-налоговый движок) · `Расчёт аннуитета` ·
`Сравнение` (рейтинг + диаграммы структуры) · `Аналитика` (многокритериальная оценка,
разложение над лучшим, диапазон риска, ценность готовности) · `Чувствительность`
(торнадо, КТГ, ставка дисконтирования) · `Справочник`.

## Пример

Заложено сравнение **5 буровых станков класса 250–270 мм (дизель)** карьера
«Сухой Лог» с реальными погодовыми данными «в расчёте» из файла `000_БСЛ-2027`:
YANGZI DR75 (аналог Epiroc DM75), Sunward SWDRT250SM / SWDRT270SM / SWDRT270B,
HIFO 75D. Замените исходные данные своими.

> ⚠️ **Цена станков в файлах поставщиков не указана** (строка инвестиций пуста) —
> в модель подставлена **оценочная** цена; уточните и замените жёлтые ячейки на листе
> «Ввод данных». Буровой инструмент (долота/штанги) заполнен по данным ТКП только для
> DR75 — по остальным станкам данные поставщика отсутствуют (0), требуют уточнения.

## Проверка

Вся книга пересчитана движком `formulas` — **ошибок нет** (0 ячеек #ЗНАЧ!/#ССЫЛКА!/…).
Кэшированные значения формул встроены (`inject_cache.py`), чтобы просмотрщики без
пересчёта (мобильные) показывали числа, а не нули.
