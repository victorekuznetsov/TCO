# Модель TCO карьерных автосамосвалов по методике аннуитета (руб/ткм и руб/т)

`Модель_TCO_автосамосвалов_аннуитет.xlsx` — расчётный файл для экономического
сравнения карьерных автосамосвалов **одного класса** по совокупной стоимости владения
за полный жизненный цикл. Построен по аналогии с моделями буровых станков и
экскаваторов, но с расчётом **производительности по методике из корпоративного файла
автосамосвалов** (`000_БСЛ-2027. Автосамосвалы от 220 т`). Генерируется скриптом
`build_truck.py` (Python + openpyxl).

```bash
pip install openpyxl formulas
python3 build_truck.py
```

## Структура репозитория


> Модели буровых станков и экскаваторов — в отдельных ветках. Здесь — только автосамосвалы.

## Метрика

Главный критерий — **удельный аннуитет затрат, руб/ткм** грузооборота, и производный
**руб/т** перевезённой массы. Аннуитет разложен на **операционный** и **инвестиционный**.
Лучший вариант — минимум.

```
Аннуитет (руб/год)   = NPV затрат / Σ(дисконт-факторов)
Удельный (руб/ткм)   = Аннуитет (руб/год) / годовой грузооборот (ткм)
Удельный (руб/т)     = руб/ткм × плечо откатки
```

Модель **пост-налоговая**: годовой поток = денежные затраты × (1 − налог) − налоговый
щит амортизации. Инвестиционный аннуитет = (цена − дисконт. остаточная) / Σ(диск.факторов).

## Производительность (транспортный цикл, лист «Производительность» исходного файла)

Ключевое отличие от моделей бурения/экскавации — часовая производительность считается по
**транспортному циклу**:

```
Время движения       = 2 · плечо / скорость · 60   (гружёный + порожний ход)
Время рейса          = (подход + погрузка + разгрузка + прочее) + время движения
Рейсов/час           = 60 / время рейса
Часовая произв.      = рейсов/час · грузоподъёмность · КИГ            (т/эфф.час)
КИО                  = КТГ · (1 − простои_смены/(60·смена))
Эффективное время    = КФВ · КИО
Объём (тыс.т)        = часовая · эфф.время
Грузооборот (тыс.ткм)= объём · плечо;   Пробег (тыс.км) = рейсы · 2·плечо
```

КИО модели **совпадает с исходным файлом**: NTE240 0,804; ESDE240 0,782; SANY 0,803;
TZCO 0,780; БелАЗ ГПФК 0,779; БелАЗ БТЛ 0,798.

## Что учитывает (полный погодовой жизненный цикл, 10 лет)

- **CAPEX**: цена (в валюте контракта по курсу), доставка/ПНР, остаточная стоимость.
- **OPEX по годам**: топливо (по грузообороту, г/ткм), ТОиР и сервис (ТО, текущие и
  капитальные/ППР ремонты, трудозатраты — по годам из данных поставщика; «рваный» график
  капремонтов учитывается дисконтированием), **шины** (по пробегу), персонал,
  транспортный налог.
- **Финансы**: амортизация (НУ), налог на прибыль (щит), дисконтирование, аннуитет.

## Листы

`Методика` · `Дашборд` (KPI, рейтинг, графики) · `Параметры` · `Ввод данных`
(до 6 машин: цена, грузоподъёмность, мощность двигателя, персонал) · `Поставщик 1…6`
(по машине: КТГ, простои, ТОиР по годам) · `Данные по годам` (сводка, тянет из шаблонов) ·
`Производительность` (транспортный цикл + погодовая таблица) · `Денежный поток`
(погодовой пост-налоговый движок) · `Расчёт аннуитета` · `Сравнение` (рейтинг +
диаграммы структуры) · `Аналитика` (многокритериальная оценка, разложение над лучшим,
диапазон риска, ценность готовности) · `Чувствительность` (торнадо, КТГ, ставка
дисконтирования) · `Справочник`.

## Пример

Заложено сравнение **6 автосамосвалов класса 220–240 т** карьера «Сухой Лог» с реальными
погодовыми данными «в расчёте» из файла `000_БСЛ-2027. Автосамосвалы`: NHL NTE 240,
Estar ESDE240 (ГПБ К), SANY SET240S, TZCO TZE240, БелАЗ 7531 (ГПФК), БелАЗ 7531 (БТЛ).
Замените исходные данные своими.

> ⚠️ **Цена самосвалов в файлах поставщиков не указана** (строка инвестиций пуста) —
> в модель подставлена **оценочная** цена; уточните и замените жёлтые ячейки на листе
> «Ввод данных». Расход топлива (90 г/ткм), шины (0,075 шт/тыс.км × 2 985 тыс.руб) и КИГ
> (0,98) заданы как общие параметры — уточните по данным ТКП/факту эксплуатации.

## Проверка

Вся книга пересчитана движком `formulas` — **ошибок нет** (0 ячеек #ЗНАЧ!/#ССЫЛКА!/…).
Кэшированные значения формул встроены (`inject_cache.py`), чтобы просмотрщики без
пересчёта (мобильные) показывали числа, а не нули.
