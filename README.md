# TCO — модели стоимости владения горного оборудования

Расчётные модели совокупной стоимости владения (TCO / LCC) горной техники.
Работа ведётся в отдельных ветках по классам оборудования:

| Оборудование | Метрика | Ветка |
|--------------|---------|-------|
| **Буровые станки** | руб/пог.м, руб/м³ | `claude/tco-drilling-rigs-simulation-5v2o0p` |
| **Автосамосвалы** | руб/ткм, руб/т | `claude/tco-haul-trucks-simulation` |
| **Экскаваторы** | руб/м³ | `claude/mining-equipment-ownership-cost-w4sq2r` |

Каждая ветка содержит генератор модели (Python + openpyxl), готовый Excel-файл
и исходные данные/ТКП подрядчиков по своему классу техники (папка `исходные_данные/`).

> Ветка `main` — только этот индекс. Исходные файлы по каждому классу техники
> перенесены в соответствующую ветку.
