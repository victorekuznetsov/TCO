# Модель TCO буровых станков по методике аннуитета (руб/пог.м и руб/м³)

Расчётные файлы для экономического сравнения буровых станков **одного класса**
(250–270 мм, дизель) по совокупной стоимости владения за полный жизненный цикл.
Построены по аналогии с моделью экскаваторов (соседняя ветка), но с расчётом
**производительности по методике из корпоративного файла буровых станков**
(`000_БСЛ-2027`). Генерируются скриптом `build_drill.py` (Python + openpyxl).

## Две версии

Скрипт собирает **две сверенные версии**, отличающиеся только допущениями (класс,
физика бурения, цены и объёмы — одинаковы; сравниваются **только одноклассники**):

```bash
pip install openpyxl formulas
python3 build_drill.py supplier   # → Модель_TCO_буровых_станков_ПОСТАВЩИК.xlsx
python3 build_drill.py producer   # → Модель_TCO_буровых_станков_ПРОИЗВОДИТЕЛЬ.xlsx
```

| Допущение            | ПОСТАВЩИК (единый норматив) | ПРОИЗВОДИТЕЛЬ (паспорт)                     |
|----------------------|-----------------------------|--------------------------------------------|
| Срок службы          | 10 лет у всех               | 12 лет (кроме HIFO 75D — 10)               |
| КТГ средний          | 0,86 у всех                 | фактический (DR75 0,91; 270B 0,90; ост. 0,86) |
| ТОиР, млн руб/год    | усреднён ≈50                | дифференцирован (DR75 28; 270B 70; ост. 49) |

Обе версии сверены с корпоративными файлами `000_БСЛ-2027` (версии 30.07.2026):
итоговый аннуитет, ранжирование и **знак межверсионной разницы совпадают**;
расхождение уровня — в пределах ≈1–3 руб/м³ (2–4%).

## Метрика

Главный критерий — **удельный аннуитет затрат, руб/пог.м** пробуренной скважины,
и производный **руб/м³** взорванной горной массы (через выход м³ с 1 пог.м).
Аннуитет разложен на **операционный** и **инвестиционный**. Лучший вариант — минимум.

```
Аннуитет (руб/год)      = NPV затрат / Σ(дисконт-факторов)
Удельный (руб/пог.м)    = Аннуитет (руб/год) / годовой объём бурения (пог.м)
Удельный (руб/м³)       = руб/пог.м / выход (м³ с 1 пог.м)
```

Модель **пост-налоговая**: годовой поток = денежные затраты × (1 − налог) − налоговый
щит амортизации. Инвестиционный аннуитет считается методом **эквивалентной годовой
стоимости (EAC)**: CAPEX распределяется на **собственный срок службы** станка
(поэтому у версии «производитель» ресурс 12 лет снижает инвестиционную нагрузку).

## Производительность (методика бурения, лист «W час» исходного файла)

Часовая производительность считается по **физике бурения**, а не по геометрии ковша:

```
Теор. скорость бурения (п.м/час) = (0,1 · N_вращ) / (2,73^(0,017·σ) · D_заряда²)
D_заряда = D_долота · k_разбура
Скважин/смену → часовая произв. → эфф. время = КФВ · КИО, КИО = КТГ·(1 − простои/(60·смена))
Объём бурения (тыс.пог.м) = часовая · эфф.время;  Объём взрывания = объём бурения · выход м³/пог.м
```

Средний годовой объём бурения модели **совпадает с корпоративным файлом** (в пределах
0,5%): DR75 104,5; 250SM 107,4; 270SM 122,3; 270B 127,3; HIFO 99,6 тыс.пог.м (версия «производитель»).

## Листы

`Методика` · `Дашборд` (KPI, рейтинг, графики) · **`Выводы`** (сравнение двух версий,
диаграмма, декомпозиция причин разницы аннуитета, методические расхождения) ·
`Параметры` · `Ввод данных` · `Поставщик 1…5` (по машине: КТГ, простои, узловой каталог
ТО/Ремонтов с ресурсом м/ч, коэффициент калибровки, расход ДТ) · `Данные по годам` ·
`Производительность` · `Денежный поток` (погодовой пост-налоговый движок) ·
`Расчёт аннуитета` · `Сравнение` · `Аналитика` · `Чувствительность` · `Справочник`.

## Что учтено при сверке с корпоративными файлами

- **Долота/штанги/расходники = 0** — в файлах `000_БСЛ-2027` их не котировал ни один
  поставщик; обнулены и в модели, иначе частичные данные ТКП только по DR75 завышали бы
  аннуитет одного станка и делали сравнение несимметричным.
- **ТОиР** калиброван «коэффициентом калибровки» под целевой уровень корпоративного файла
  (тыс.руб/год) отдельно для каждой версии; узловой каталог (ресурс м/ч) — по HIFO 75D
  как классовому шаблону.
- **Выход м³/пог.м** и профиль дисконтирования «рваного» графика капремонтов — основной
  источник остаточного расхождения (2–4%); ранжирование и знак Δ версий не меняются.

## Проверка

Обе книги пересчитаны движком `formulas` — **ошибок нет** (0 ячеек #ЗНАЧ!/#ССЫЛКА!/…).
Кэшированные значения формул встроены (`inject_cache.py`), чтобы просмотрщики без
пересчёта (мобильные) показывали числа, а не нули.

> Модель экскаваторов и автосамосвалов — в отдельных ветках. Здесь — только буровые станки.
> Исходные файлы и ТКП подрядчиков — в каталоге `исходные_данные/`.
