# Методика оценки стоимости владения горных машин (TCO / LCC)

Excel-модель для экономического сравнения нескольких моделей горного оборудования
**одного класса** (экскаваторы, карьерные самосвалы, погрузчики, бульдозеры, буровые
станки) по критерию **совокупной стоимости владения** за полный жизненный цикл.

## Файл

`Методика_TCO_горного_оборудования.xlsx` — рабочая книга с 7 листами.
Генерируется скриптом `build_tco.py` (Python + openpyxl).

```bash
pip install openpyxl
python3 build_tco.py
```

## Структура книги

| Лист | Назначение |
|------|-----------|
| **Методика** | Описание подхода, состав затрат, формулы, порядок работы |
| **Параметры** | Глобальные допущения: ставка дисконтирования, цены топлива/труда, эскалации |
| **Ввод данных** | Исходные данные по 1–4 вариантам (жёлтые ячейки — ввод) |
| **Расчёт TCO** | Автоматический расчёт всех статей жизненного цикла |
| **Сравнение** | Дашборд: рейтинг, рекомендация, диаграммы структуры затрат |
| **Чувствительность** | Торнадо-анализ драйверов + чувствительность к утилизации |
| **Справочник** | Ориентировочные диапазоны по классам техники |

## Что учитывает модель

- **CAPEX**: цена, доставка/монтаж/ПНР, стартовый ЗИП, финансирование (кредит/лизинг),
  остаточная стоимость.
- **OPEX**: топливо/энергия, смазочные материалы, шины/ходовая/ГЭТ, оплата труда.
- **ТОиР**: плановое ТО и капитальные ремонты (аннуитизированы по наработке).
- **Постоянные**: страхование, налоги.

## Методология

Все потоки приводятся к текущей стоимости (**NPV**) по ставке дисконтирования (WACC).
Категории затрат растут с индивидуальной эскалацией и приводятся через коэффициент
растущего аннуитета:

```
GAF(g, r, N) = (1 − ((1+g)/(1+r))^N) / (r − g)
```

Итоговые показатели:
- **TCO (NPV)** — совокупная приведённая стоимость владения;
- **EAC** — эквивалентная годовая стоимость = TCO / коэф. аннуитета(r, N);
- **удельный TCO на мото-час**;
- **удельный TCO на тонну** продукции (levelized cost) — главный критерий сравнения,
  корректно учитывающий разницу в производительности.

## Как пользоваться

1. На листе **Параметры** задайте макродопущения.
2. На листе **Ввод данных** заполните жёлтые ячейки по каждому варианту (один класс).
3. Смотрите результаты на листах **Сравнение** и **Чувствительность** —
   расчёт обновляется автоматически.

> В книге заложен рабочий пример: сравнение четырёх гидравлических экскаваторов ~250 т.
> Замените исходные данные своими.

# Модель TCO экскаваторов по методике аннуитета (руб/м³)

`Модель_TCO_экскаваторов_аннуитет.xlsx` — расчётный файл, воспроизводящий логику
корпоративной модели сравнения карьерных экскаваторов одного класса
(**пост-налоговый дисконтированный аннуитет руб/м³**), но в виде чистого
переиспользуемого input-driven инструмента. Генерируется скриптом `build_exc.py`.

## Метрика

Главный критерий — **удельный аннуитет затрат, руб/м³** вынутой горной массы,
разложенный на **операционный** и **инвестиционный**. Лучший вариант — минимум руб/м³.

```
Аннуитет (руб/год) = NPV затрат / Σ(дисконт-факторов)
Удельный аннуитет (руб/м³) = Аннуитет (руб/год) / годовой объём (м³)
```

Модель **пост-налоговая**: годовой поток = денежные затраты × (1 − налог) − налоговый
щит амортизации. Инвестиционный аннуитет = стоимость / Σ(дисконт-факторов).

## Что учитывает (полный погодовой жизненный цикл, 10 лет)

- **Производительность**: ковш → порода в ковше → ковшей на самосвал (ОКРУГЛ.ВВЕРХ) →
  самосвалов/час → т/час → м³/час → годовой объём через КТГ, простои, КИО.
- **Листы-шаблоны «Поставщик 1…6»** (по одному на машину): по годам задаются простои,
  статьи ТОиР (ТО + текущие/капитальные ремонты + сервис), удельный расход ДТ и расходники
  на ковш. **КТГ и ИТОГО ТОиР считаются автоматически** (из простоев и из статей).
  Заполняются данными от поставщика.
- **Сводка «Данные по годам»**: **тянет всё напрямую** из листов «Поставщик N» (только
  просмотр). Правки вносятся в листах-шаблонах — сводка и весь расчёт (аннуитет, дашборд)
  обновляются автоматически.
- **«Рваный» график**: годы капремонтов дают всплеск затрат, что корректно учитывается
  дисконтированием. Данные примера — реальные («в расчёте», АО «Полюс»).
- **Прочие затраты**: персонал; опциональная эскалация цен и остаточная стоимость.
- **Финансы**: амортизация (НУ), налог на прибыль (щит), **остаточная стоимость**,
  дисконтирование, эквивалентный аннуитет. Цена в CNY/USD/EUR/RUB по курсу.
- **Результат**: удельный аннуитет **руб/м³ и руб/т**, разбивка на операционный +
  инвестиционный, NPV стоимости владения, траектория аннуитета по годам.

## Листы

`Методика` · `Дашборд` (KPI, рейтинг, графики) · `Параметры` · `Ввод данных` (до 6
экскаваторов) · `Поставщик 1…6` (листы-шаблоны по машинам) · `Данные по годам` (сводка,
тянет из шаблонов) · `Производительность` · `Денежный поток` (погодовой движок) ·
`Расчёт аннуитета` · `Сравнение` (рейтинг + диаграммы) · `Чувствительность` (торнадо,
КТГ, ставка дисконтирования) · `Справочник`.

## Проверка

Вся книга пересчитана движком `formulas` — **ошибок нет**. С реальными погодовыми
данными модель воспроизводит аннуитет исходной корпоративной модели на горизонте
10 лет: Komatsu PC2000-8 — 48,71 против 48,68 руб/м³ (Δ0,03); остальные машины
совпадают с внутренним расчётом источника на год 10.
